# 指标说明：计算方式与精度判读（scripts/evaluate_bench.py 口径）

> 📖 **术语与实验编号**（B0/AGL/ASL/case5/GCF…）统一见《[术语表](术语表.md)》；指标计算与判读见《[指标说明](指标说明.md)》。


适用范围：`results/bench_*.json|.csv|.md` 与《优化策略总结》《baseline_report》《AGL改造报告》中出现的全部指标。

统一记号：σ = 观测消光 (km⁻¹，ACDL 532nm Ext_mean)，σ̂ = 模型预测消光；
逐 (样本 i, 层 l) 计算。**所有逐层指标只在 `isfinite(σ) ∧ isfinite(σ̂)` 的同一掩膜上计算**
（观测与预测同批同掩膜，杜绝口径混用）。分带口径：ASL 产物按海拔、AGL 产物按离地高度。

**怎么读本文**：每个指标给四件事——①怎么算；②它表征哪个维度的精度；③数值大小如何解读
（含本项目实测锚点）；④陷阱。最后一节是"我想判断 X，该看哪个指标"的决策表。

---

## 1. 基础误差四件套

### 1.1 MAE（平均绝对误差）

- **计算**：`MAE = mean|σ̂ − σ|`，单位 km⁻¹。
  例：某层两个样本误差 +0.02 / −0.06 → MAE = 0.04。
- **表征**：预测值**平均偏离观测多远**（绝对量级），是最朴素的"差多少"。
- **大小如何解读**：**必须与该层观测信号的量级对照**才有意义——本项目近地面消光中位数仅
  0.065 km⁻¹，B0 的 0–1km 带 MAE=0.0672 意味着典型误差与信号**同量级**（模型基本没有分辨力，
  相当于"报个平均值"）；MAE 降到 0.02 以下才谈得上分辨能力。
- **陷阱**：跨层/跨带直接比 MAE 没有意义（高层 σ 本来就小一个量级）→ 跨层比较请用 nMAE。

### 1.2 nMAE（归一化平均绝对误差）——跨层可比的**主指标**

- **计算**：`nMAE = MAE / mean(σ)`（带内观测均值），无量纲百分比。
  例：带内观测均值 0.118、MAE 0.0672 → nMAE = 57%。
- **表征**：**误差占信号的比重**——消掉量级差异后，"预测得准不准"。
- **大小如何解读（本项目经验标尺）**：

  | nMAE | 含义 |
  |------|------|
  | <30% | 较好：误差不到信号的三分之一，有实用分辨力（本项目 >10km 带 = 30%，恰在此线） |
  | 30–50% | 中等：能分辨量级，细节不足 |
  | >50% | 差：误差超过信号一半，接近"报均值"（**本项目全部低层带 = 53–65%，这正是优化的动机**） |

- **陷阱**：分母是**该带观测均值**——观测均值小的带（如清洁期）nMAE 天然偏高，跨时期比较要看清分母。

### 1.3 RMSE（均方根误差）

- **计算**：`RMSE = sqrt(mean((σ̂−σ)²))`。
- **表征**：对**大误差平方惩罚**后的整体误差；与 MAE 联合读：**RMSE ≫ MAE → 误差集中在少数
  大值样本**（本项目沙尘型个例），RMSE ≈ MAE → 误差均匀分布。
- **大小如何解读**：同 MAE 一样需对照信号量级；本项目 0–1km 带 RMSE/MAE ≈ 1.3–1.5 → 存在
  少数大误差样本但未失控（比值 >2 才算尾部失控）。
- **陷阱**：对离群点敏感，沙尘个例一个 1.2 km⁻¹ 的 bin 就能拉高整带 RMSE——判断"总体精度"
  用 nMAE，判断"尾部有没有失控"才看 RMSE/MAE 比值。

### 1.4 MB（带符号平均偏置）

- **计算**：`MB = mean(σ̂ − σ)`，正=整体高估，负=整体低估。
- **表征**：**总量型误差**——模型是不是系统性偏高/偏低。这是"有方向"的误差，与 nMAE
  （无方向的散度）配对才能完整刻画精度。
- **大小如何解读**：B0 各带 MB 仅 −0.001~−0.008 km⁻¹（占信号 1–15%）→ **没有强总量偏差**；
  对比 E2b 实验：低层 MB 冲到 −0.019（占信号 ~30%）→ 总量被系统性低估，一眼可见。
- **与 nMAE 的配对判读（核心口诀）**：
  - MB≈0 且 nMAE 大 → **重分布型**误差：时高时低互相抵消，"总量对、位置错"；
  - MB 明确负/正 → **总量型**误差：整体低估/高估，先修偏置再看散度。

## 2. 线性回归对：slope / intercept（暴露"压缩"）

- **计算**：对 (σ, σ̂) 逐层/逐带做最小二乘 `σ̂ = a·σ + b`（`np.polyfit(σ, σ̂, 1)`）。
  slope = a（斜率），intercept = b（截距）。
- **表征**：**动态范围保真度**——模型输出的"起伏幅度"与观测是否成比例。
  - slope = 1, intercept = 0：完美（预测是观测的等比复制）；
  - **slope < 1 且 intercept > 0：动态范围被压缩**——小值被抬、大值被压，模型"报均值"倾向的
    定量刻画；
  - slope > 1：过度放大（通常是过拟合尾部）。
- **大小如何解读（本项目主病灶就在这）**：B0 低层 slope **0.35–0.55**——意味着观测里 1.0 的
  波动模型只输出 0.4 左右，**58% 的动态范围被压掉**；OD slope 0.810 同理。AGL 改造后 GCF slope
  0.529→0.699 即"压缩缓解"的量化。**slope 距 1 的距离 = 可修复的判别力损失**，是本任务比 R²
  更有行动价值的指标。
- **陷阱**：slope 是"统计倾向"，slope=1 不保证逐样本准（还需 MB/nMAE 配合）；观测方差小的层
  slope 不稳定（慎读，见 n 警示）。

## 3. R²（决定系数）——**已降为附图口径**

- **计算**：`R² = 1 − Σ(σ−σ̂)² / Σ(σ−σ̄)²`，分母是**该层观测自身的方差**。
- **表征**：预测解释了该层观测方差的多大比例——**同一层内**的相对水平。
- **大小如何解读与为何降级**：R² 的分母因层而异（高层 σ 小、方差小），**跨层不可比**：
  B0 高层 L26 R²=0.81 vs 低层 L00 R²=0.16，并不代表高层"好 5 倍"——高层信号平缓，报均值也能
  得高 R²。所以路线图规定：主报告用 nMAE/MB/slope，**R² 只作同层纵向对比的附图**（如
  AGL 改造前后 L00 0.164→0.313 的翻倍，同口径纵向对比是合法用法）。
- **陷阱**：对"报均值"的行为反而宽容（均值预测 R²≤0），绝不用 R² 单独下结论。

## 4. 柱含量：OD 及其指标族

### 4.1 OD（整柱光学厚度）——先算出"柱总量"才能谈相对误差

- **计算**：`OD = Σ_l σ_l·Δz_l`，Δz 为层厚（AGL 产物 = 层段设计厚度；L00 = H₀₀ − DEM）。
  **两侧用同一套有效层掩膜**（该层 isfinite(σ) 才计入，预测同掩膜求和）——保证 obs/pred
  积分的是同一根柱子；**绝不与 ACDL 官方 AOD 混用**（反演路径不同）。
- **表征**：垂直整柱的气溶胶总量。B0 留出集 OD 均值 ≈ 1.02（无量纲）。

### 4.2 OD 相对误差（bias 与 |rel| MAE）

- **计算**：`rel = (OD̂ − OD)/OD`（逐样本）；
  **bias** = mean(rel) → **总量系统偏移**；**|rel| MAE** = mean(|rel|) → **逐样本散度**。
- **大小如何解读**：

  | 指标 | B0 实测 | 解读 |
  |------|--------|------|
  | bias = **−1.2%** | 总量几乎无偏（"平均意义上的柱总量是对的"） |
  | \|rel\| MAE = **24.7%** | 单次预测的柱总量平均偏离四分之一——**总量准 ≠ 逐样本准** |

- **陷阱**：bias 小 + |rel| 大 = 高低相抵（重分布），必须与逐层 MB/slope 联读。

### 4.3 Gfrac(EE)——领域标准的"满意率"

- **计算**：`Gfrac = mean( |OD̂ − OD| ≤ 0.05 + 0.15×OD )`。EE 包络 = 预测允许落在
  1:1 线 ±(0.05 + 0.15×观测值) 的带内；**≥66% 为领域满意线**（MODIS 陆地 Levy 2010 的
  550 nm 形式，**本项目 532 nm 沿用**，论文须注明）。
- **表征**：**逐样本意义上"多少比例的预测达到了业务可接受精度"**——是比相关系数更贴近
  应用的"及格率"。
- **大小如何解读**：B0 = **56.3% < 66% → 不满意**（每 5 次预测约 2 次出包络）；AGLB0 = 57.0%。
  若 Gfrac 达 66–75% 即达到国际同类产品水准。
- **陷阱**：EE 是**列级**指标（对整柱 OD）；"逐层 EE 内比例"是另一个数（本项目 84.9%），
  两者不可混写（见 bench 图 (d) 面板注释的口径分离）。

### 4.4 OD slope / intercept

- 同 §2，但作用在柱总量上：B0 slope 0.810 / intercept 0.115 → **柱含量的动态范围也被压缩**
  （干净天抬、污染天压），这直接限制"用预测 OD 反演 PM2.5 极端事件"的能力。

## 5. GCF（近地面占比）——参考口径族

- **计算**：`GCF = Σ_{层底<500m} σ̂Δz / Σ_all σ̂Δz`（比值，量纲自动消去）。
  AGL 产物下"层底<500m"为**离地高度**（物理正确）；真值端要求近地面窗口各层全有效
  （缺测不能当 0）→ 只有 58.9% 样本可评估（AGL 后；ASL 时代仅 6%）。
- **表征**：柱总量中"贴地"部分的比例——**与近地面 PM2.5 最直接相关的量**。
- **大小如何解读**：B0-ASL R²=0.423、slope=0.529 → 方差一半没学出来；B0-AGL R²=0.605、
  slope=0.699 → 明显改善但 slope 仍 <1（极端清洁/极端污染个例仍被压缩）。
- **陷阱**：GCF 是比值——分子分母同错会抵消，GCF 好 ≠ 每层都好；且 n 小（窗口完整性要求）。

## 6. 对数差值曲线（log10(σ̂/σ)）

- **计算**：逐 (样本,层) 取 `log10(σ̂/σ)`（仅 σ>1e-8 且 σ̂>1e-8 的对），逐层统计中位数与
  25–75 分位。
- **表征**：**相对误差的对称视角**。log 域里 +0.3 与 −0.3 等距（×2 与 ÷2 对称），克服了
  原始误差"高值主导"的偏差。
- **大小如何解读**：**中位线 = 0** → 典型样本无系统偏差；每 +0.3 = 典型样本高估 2 倍。
  B0 低层 +0.03~+0.08（典型样本高估 7–20%）同时 MB 为负 → **典型样本略高、高消光尾部
  （沙尘）被大幅低估**——"尾部缺失"的诊断就来自这条曲线与 MB 的矛盾。
- **陷阱**：只统计正值对（σ 或 σ̂ ≤0 的对被剔除），负预测多的模型该指标偏乐观。

## 7. 逐层有效样本数 n 与"红圈"警示

- **计算**：每层 `n = Σ isfinite(σ) ∧ isfinite(σ̂)`。
- **表征**：该层结论的**统计可信度**。n<500 的层（图上红圈）任何指标都慎读；
  本项目 L00 仅 29.6%（ASL）/57.5%（AGL）有效——低层结论的样本基础天然薄弱。
- **陷阱**：有效率本身也是"覆盖产品"——AGL 改造把 L00 有效率 29.2%→57.5% 属于**产品覆盖**
  的改善，与精度改善是两回事。

---

## 8. 分层带定义

按**层中点高度**分带（AGL 产物用离地高度）：层底 bot₀=0、bot_k=top_{k−1}、mid=(bot+top)/2，
按 mid 落入 0–1/1–3/3–5/5–10/>10 km。带内 nMAE/MB 按**样本数加权**平均。
实测归属：0–1km=L00–L07，1–3km=L08–L14，3–5km=L15–17，5–10km=L18–22，>10km=L23–31。

## 9. 决策表：我想判断 X，该看哪个指标

| 我想判断… | 首选指标 | 配对指标 | 本项目现状（B0→AGLB0） |
|-----------|---------|---------|----------------------|
| 总体精度好不好 | 带 nMAE | MAE（量级） | 低层 57.0%→58.8%（更难人群） |
| 是否系统性偏高/偏低 | 带 MB / OD bias | slope | MB −0.008→−0.002；bias −1.2%→+0.9% |
| 起伏幅度学没学到 | slope（距 1 的距离） | nMAE | 低层 0.42；OD 0.810→0.733 |
| 单次预测能不能用 | Gfrac(EE)（列级） | \|rel\| MAE | 56.3%→57.0%（未达 66%） |
| 垂直结构对不对 | 均值剖面 r / 逐层 R²（同层纵向） | — | 全域均值剖面 r=0.998 |
| 近地面产品可用性 | L00–L02 有效率 + 首有效层 | — | 29.2%→57.5%；首有效层全=L00 |
| 核心约束量（GCF） | GCF R² / slope / n | GCF MAE | n 2079→3903；R² 0.423→0.605 |
| 尾部/极端事件 | RMSE/MAE 比值 + log10 差值曲线 | med log10 ratio | 低层 +0.04~+0.08（典型略高、尾部缺） |
