# 指标说明（评估台 evaluate_bench.py 口径）

适用范围：`results/bench_*.json|.csv|.md` 与《优化路线执行报告.md》《baseline_report.md》中出现的全部指标。
统一记号：σ = 观测消光 (km⁻¹，ACDL Ext_mean)，σ̂ = 预测消光；逐 (样本 i, 层 l) 计算后按口径聚合。
**所有逐层指标只在 `isfinite(σ) ∧ isfinite(σ̂)` 的同一掩膜上计算**（观测与预测同批同掩膜，杜绝口径混用）。

---

## 1. 逐层 / 全局基础指标

| 指标 | 公式 | 含义与判读 |
|------|------|-----------|
| **MAE** | `mean \|σ̂−σ\|` | 平均绝对误差，km⁻¹。对量纲敏感：低层数值大、高层小，**跨层不可比**，故用 nMAE 补 |
| **nMAE** | `MAE / mean(σ)`（带内观测均值） | 归一化 MAE，**跨层可比**的主指标。B0 低层 ~57% ≈ 预测误差约等于观测均值的一半以上 |
| **RMSE** | `sqrt(mean (σ̂−σ)²)` | 对大误差平方惩罚；与 MAE 差距大 → 误差集中于少数大值样本（尾部） |
| **MB**（带符号） | `mean(σ̂−σ)` | 平均偏置。MB≈0 但 nMAE 大 → "重分布型"误差（时高时低互相抵消）；MB 持续负/正 → "总量型"偏置 |
| **slope / intercept** | OLS：`σ̂ = a·σ + b`（`np.polyfit(σ, σ̂, 1)`） | **slope<1 + intercept>0 = 动态范围压缩**：大值低估、小值高估。B0 低层 slope 0.35–0.55 是核心病灶；slope≈1、intercept≈0 才是理想 |
| **R²** | `1 − Σ(σ−σ̂)² / Σ(σ−σ̄)²` | 分母是观测方差，**跨层不可比**（高层量级小、方差小，R² 易虚高/虚低）→ 按路线图降为附图，主报告用 nMAE/MB/slope |

## 2. 分层带指标（0–1 / 1–3 / 3–5 / 5–10 / >10 km）

- **层带归属**：按层**中点高度**分带。层顶取 `layer_geometry.json` 的样本均值高度，层底 = 上一层顶（L00 底=0），mid=(bot+top)/2。
- 带内指标 = 带内各**层**指标按样本数 n 加权平均（nMAE/MB），MAE 为层均值；`n_obs` = 带内 (样本×层) 有效对数。
- 分带结果（case5 产物实测）：0–1km=L00–L07，1–3km=L08–L14，3–5km=L15–L17，5–10km=L18–L22，>10km=L23–L31。
- **判读**：低层带 nMAE 是"训练重点"主指标；注意 L00–L02 有效样本稀（见《低层缺失诊断.md》），带内 n 小于直觉。

## 3. 柱含量 OD 与 Gfrac(EE)

| 量 | 公式 | 说明 |
|----|------|------|
| **OD**（柱光学厚度） | `OD = Σ_l σ_l·Δz_l`，Δz 由层高差算（L00 用 `H00 − Z_sfc`） | 无量纲；**两侧用同一套有效层掩膜**（`isfinite(σ)` 逐样本），绝不与 ACDL 官方 AOD 混用（反演路径不同） |
| **OD 相对误差 rel** | `(OD̂ − OD) / OD` | bias = mean(rel)（总量偏置）；\|rel\| MAE = mean(\|rel\|)（逐样本散度） |
| **Gfrac(EE)** | `mean( \|OD̂−OD\| ≤ 0.05 + 0.15·OD )` | EE 包络内比例，**≥66% 为领域满意线**（MODIS 陆地 Levy 2010 的 550nm 形式，**532nm 沿用**，需注明）；B0 = 56.3% 未达标 |
| **OD slope/intercept** | OLS：`OD̂ = a·OD + b` | B0: a=0.810, b=0.115 → 柱含量动态范围被压缩、干净样本高估（b>0 抬底） |

## 4. GCF（近地面占比，参考口径）

- 定义：`GCF = Σ_{层底<500m} σ̂·Δz / Σ_all σ̂·Δz`（比值，量纲自动消去）。
- 真值端要求**近地面窗口各层全部有效**（缺测不能当 0），故 n 少（B0 n=2079，占 30%）。
- 真值分母=有效层积分，预测分母=全 32 层积分——高层缺测时口径不对称，但高层有效率≈100%，实际影响可忽略。
- 本阶段不建模 GCF（abs 口径），仅作参考指标追踪。

## 5. 对数差值曲线（分位带图右栏）

- 逐 (样本,层)：`log10(σ̂/σ)`，只取 σ>1e-8 且 σ̂>1e-8 的对；逐层取中位数与 25–75 分位带。
- **判读**：中位线 ≈ 0 → 典型样本无系统偏差；中位线 >0 但 MB<0 → 典型样本略高估、**高消光尾部被低估**（B0 低层的形态）；整条曲线下移 = 总量被压（E2b 的形态）。
