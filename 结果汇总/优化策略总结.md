# 优化策略总结：从"调参失败"到"垂直坐标改造"

> 📖 **术语与实验编号**（B0/AGL/ASL/case5/GCF…）统一见《[术语表](术语表.md)》；指标计算与判读见《[指标说明](指标说明.md)》。


（2026-09-28/29，demo 分支；依据《优化路线讨论.md》Step 0–5 执行 + AGL 垂直坐标改造）

**TL;DR**：训练侧消融（log 目标/softplus/高度加权）全部失败 → Step 0/诊断证明**瓶颈不在训练，在任务定义**：
固定气压层分层让高原近地面"没有层可用"且层号语义被地理混淆 → 改为 **AGL（离地高度）地形跟随分段**并重匹配重训：
近地面覆盖翻倍（L00 29.2%→57.5%）、GCF 覆盖 6%→58.9%（R² 0.423→0.605）、层语义全域统一；逐样本精度持平（更难人群上）。

## 1. 原有方式的缺陷 —— 为什么需要这次优化

### 1.1 缺陷一：固定气压层被地形切割，低层监督先天缺失（主因）

#### 概念速览：什么是"DEM 越过层顶"？

> **一句话：ERA5 的 32 层像"从海平面往上摞的固定抽屉"；DEM 是当地地板的高度。
> 地板升到某层抽屉的上沿之上，那层以下的抽屉就全被压进地下——地下没有大气也没有激光信号，该层观测必然为 NaN（不是缺测，是根本不存在）。**
>
> ```
> 海拔(km)
>   31 ┬───────── L31(10hPa)
>      │
>  10 ┼───────── L23
>      │
> 5.0 ┼───────── L14
>      │                     ┌────────────────┐
> 1.0 ┼───────── L08        │  高原 DEM=1000m │ ← 地面在这里
>      │  ┌─────────┐        │
> 0.63┼──┤ L02     │        │  地下:无激光信号 │
>      │  │ L01     │        │  → Ext = NaN   │
> 0.05┼──┤ L00     │        │                │
>      ├──┴─────────┴── 0 ──┴────────────────┘
>        平原 DEM≈30m:             高原 DEM=1000m:
>        L00 在地表之上,有观测      L00–L07 整段被埋 → 全 NaN
> ```
>
> - **层顶**：一层抽屉的上沿海拔（如 L02 上沿 ≈ 634 m）；
> - **"DEM 越过层顶"**：当地地面比这层的上沿还高 → 这一层整段在地下；
> - **图 2 的阶梯怎么读**：地形像一把刀从下往上切抽屉——DEM 越过哪层的层顶，哪层的有效率就应声跳水；
> - **AGL 改造做的事**：把抽屉从海平面挪到各地自己的地板上钉住（段边界 = DEM + 离地高度），
>   让每个地方都有自己的 L00 = "地表上方 0–50 m"。

原匹配用 ERA5 的 32 个**固定气压层**（1000→10 hPa）做段边界。气压层高度以**海平面**为基准
（1000 hPa ≈ 47 m），不随地形成像；而研究域内 DEM 中位 298 m、p90 达 2 567 m（含青藏高原）。
DEM 高于层顶的样本，该层段整体落在地下 → ACDL 无 bin 可聚合 → Ext_mean = NaN。

![低层缺失成因分解](C:/Users/admin/Desktop/Main_ACDL_ERA5_SpatiotemporalAttention_DL/结果汇总/figures/diag_lowlayers_decompose.png)

**图 1**：L00–L02 的缺失 **91–95% 是"硬几何"**（红色 A 类）——不是 QC 错杀，是观测在几何上不存在；
云 QC 的贡献（蓝色 C）已被 case5 口径回收（L00 0.8%→29.2%）。数据铁证：段顶在地表之上时
L00–L05 有效率 73–80%，在地下时平均仅 34%。

![地形阶梯](C:/Users/admin/Desktop/Main_ACDL_ERA5_SpatiotemporalAttention_DL/结果汇总/figures/diag_lowlayers_demband.png)

**图 2**：逐地形带的有效率阶梯——每层有效率都在"DEM 越过层顶"处断崖，几何控制的形态一目了然。

### 1.2 缺陷二：层号语义被地理混淆

固定海拔网格下，高原（>2.6 km）的近地表消光落进 **L13**——平原 2.5–3.1 km 自由大气的层号。
同一层号被两种物理含义争夺（双峰目标），输入特征（该层 T/RH）也随之语义漂移。
实测各地形带"首个有效层"：平原=L00、盆地≈L05、高原>2.6km=**L13**。

### 1.3 缺陷三：连带口径 bug（修复前持续损害柱量指标）

| bug | 后果 |
|-----|------|
| ACDL `DEM_Surface_Elevation` 字段单位是 **km，脚本按 m 用**（天山处读数 1.6） | 逐 bin 剔地下掩膜形同虚设 |
| 训练 dz₀ = H₀₀ − Z_sfc ≤ 0 被 clip 成 0 | **88% 样本的 L00 柱贡献被清零**（有观测的样本里 70% 再遭清零），L00 双重幸存仅 8.7% |
| GCF 要求"层底<500m 窗口全有效" | 高原样本整体退出 → **GCF 覆盖仅 6%**（2,079/34,860），且"近地面占比"实际由 L01–L07 撑起 |

### 1.4 训练侧改进为什么救不了（消融证据）

在 ASL 口径上按路线图做了全部低成本训练消融（同 seed、同留出集、噪声底=0）：

| 实验 | 改动 | 结果 | 判定 |
|------|------|------|------|
| E0 | 对照重跑 | 与 B0 逐位一致 | 确定性成立 |
| E2b | 目标取 log | 低层 MAE −3%，但柱总量 bias −1.2%→**−8.3%** | 权衡→回退 |
| E2c | softplus 非负 | 负值清零但**所有主指标恶化**（GCF R² 0.42→0.32） | 回退 |
| W2 | 低层加权 exp(−h/3km) | 低层 MAE 反升 +2.6%，Gfrac −13.5pp | 回退 |
| W3 | 硬截断 <5km | OD bias **+92%**、GCF R² 转负 | 崩溃 |

**结论（决策树终点）**：瓶颈不在训练重点/损失配置——**给"几何上不存在的观测"加权，无法创造监督**。
这直接指向上面的分层定义问题。

## 2. 优化方法与原理

### 2.1 方法：AGL（离地高度）地形跟随重分段

核心思想：**层号的语义从"海拔带"改为"离地高度带"**——每个样本以自己的真实地表为零点分段，
平原和高原的 L00 都= "当地地表上方 0–50 m"。

实现（`Match_ACDL_ERA5_FromScratch.py --vertical agl`，默认 asl 保持历史可复现）：

1. **AGL 边界表**：33 边界/32 段（0–30 km，低层 50 m 加密、高层渐疏）；顶部压缩
   `dem + agl ≤ 30 km`（ACDL 高度上限），AGL_TOP_SPLIT=12 km 以下永不压缩（保近地面分辨率）；
2. **DEM 单位修复**：`DEM × 1000`，逐组 DEM_m 存入产物新列；
3. **特征构建**：每样本取 z>DEM 的气压层构成 T/RH–高度剖面，段特征=段中点插值；
   低于最低有效层的薄段用最低两层**局地递减率外推+限幅**（边界层内典型误差 1–3°C）；
4. **训练侧适配**（脚本零架构改动）：读 Meta 自动识别口径；dz/GCF 改用 DEM_m；
   **GCF = 层底 <500 m AGL** 的占比（物理正确的新定义）。

原理依据：ERA5 气压层的地下外推值不可信、ACDL 地下无观测——AGL 把"观测存在的空间"
（各样本地表以上）完整映射到 32 个输出维度上，消除"一半输出维度对一半样本永远 NaN"的结构性浪费，
同时让"近地面"成为全域一致的概念。

### 2.2 配套：评估台先行（Step 1 立尺子）

`evaluate_bench.py` 四指标（分层带 MAE/nMAE、整柱 OD 相对误差+Gfrac(EE)、逐层 MB、slope/intercept）+
均值口径一致性图。**没有评估台，后面所有"改善/恶化"的判断都无从谈起。**

### 2.3 顺带修复与工具沉淀

ACDL DEM 单位、`--with-stats` 建议、`diagnose_low_layers.py`（缺失归因）、
`plot_case_profiles.py`（个例廓线）、`plot_profile_agreement_modes.py`(平均口径一致性)、中文出版级样式。

## 4. 遗留问题与下一步（按性价比）

1. **L00 加厚至 0–100 m**：L00 现仅 50 m=2 bin，任一 bin 被 QC 剔即整段 NaN（L00 57.5% vs
   L01 100m 段 73.1% 的厚度效应）。改边界表一处 + 2h 重匹配，预计 ~73%；
2. **ERA5-Land 2m 锚点**替换递减率外推（数据已在盘上，schema 不变）；
3. **`--with-stats` 重匹配**精确归因 L00 残余缺失（产品侧 fill/超界占比）；
4. **AGL 数据上重跑 Step 2/3 消融**验证旧结论是否迁移；
5. **信息量升级**（治本）：slope<1 的尾部压缩根源是 ERA5 无气溶胶信息——接风场 u/v 或 AOD；
6. 多种子显著性（≥3 seeds）后再对外报数。
