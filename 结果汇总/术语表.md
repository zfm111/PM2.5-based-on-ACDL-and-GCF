# 术语表：项目专有名词与实验编号体系

（各文档中的项目专有概念集中在此解释；指标的计算与判读另见《[指标说明](指标说明.md)》）

## 一、实验编号体系

命名规则：**字母 = 实验族，数字/后缀 = 具体配置**。所有实验共用同一留出集（seed=42，N_test=6,972），对比口径统一为评估台四指标。

| 编号 | 全称/含义 | 一句话说明 |
|------|----------|-----------|
| **B0** | **Baseline 0** | **优化前原始基线模型**：ASL 口径 + abs 目标 + 等权损失 + seed 42，产物 `runs/train_fixed_case5_abs`。所有对比的回退点 |
| E0 | 对照重跑 | 与 B0 配置全同、重跑一遍 → 与 B0 逐位一致，证明代码改动零扰动、单次运行噪声底=0 |
| E2a | Step2-a 输入按层标准化 | **已取消**：核实发现 V2 已逐列标准化（无操作） |
| E2b | Step2-b 目标取 log | ln(clip(y)) 后训练；低层微改善但柱总量 bias 恶化 → 不叠加 |
| E2c | Step2-c softplus 非负输出 | 负值清零但全面恶化 → 回退 |
| W2 / W3 | Step3 加权消融 | W2=低层加权 exp(−h/3km)；W3=硬截断(层底<5km 才计损失)。均全面恶化 → 证明"瓶颈不在训练重点" |
| **AGLB0** | **AGL 版 B0** | AGL 重匹配数据 + B0 同配置重训，产物 `runs/train_agl_b0`。与 B0 对比即"垂直坐标改造"的收益 |

## 二、垂直坐标与分层（本次优化的核心概念）

| 术语 | 解释 |
|------|------|
| **ASL** | Above Sea Level，**海拔口径**：32 层段边界钉在固定海拔上（历史口径）。缺陷：高原近地面无层可用、层号语义被地理混淆 |
| **AGL** | Above Ground Level，**离地高度口径**（本次改造）：段边界 = 各样本 DEM + 固定离地高度边界表。每个地方都有自己的 L00="地表上方 0–50m" |
| 气压层 | ERA5 的 32 个固定气压面（1000→10 hPa）。高度以海平面为基准、全球一致，**不随地形成像**（1000hPa ≈ 47m 海拔） |
| 层顶 / 层底 | 一层段的上/下沿海拔（ASL）或离地高度（AGL）。训练端 H 列存段顶 |
| **硬几何缺失** | DEM 越过某层层顶 → 该层整段在地下 → ACDL 无 bin → Ext 必为 NaN。占 L00–L02 缺失的 91–95%（见《低层缺失诊断》） |
| L00…L31 | 32 个层段的自下而上编号。**注意**：ASL 与 AGL 产物中同层号覆盖的物理高度不同，不可逐层混比 |
| AGL 边界表 | 33 个离地高度边界（0–30km，低层 50m 加密）；顶部压缩规则保证 dem+agl ≤ 30km |
| 顶部压缩 | 高地形样本把 TOP_SPLIT(12km) 以上的边界线性压入 [12km, 30km−dem]，保近地面分辨率不牺牲 |

## 三、数据与匹配

| 术语 | 解释 |
|------|------|
| **ACDL** | 星载激光雷达（532nm）大气气溶胶消光探测产品，沿轨迹每 24m 一个垂直 bin（海拔 −0.96~30km），是本项目的**真值来源** |
| **ERA5** | ECMWF 再分析气象场。本项目用其 0.25° 气压层（T/RH/位势）+ 单层场（BLH/TCWV/Z_sfc）作为**模型输入**；ERA5 本身不含气溶胶信息 |
| MatchV2 | 匹配产物格式（v7.3 mat）：每行 = 一个 (0.25° 格点, 最近整点) 组的 32 层气象特征 + 32 层 ACDL 平均消光 |
| Ext_mean_L** | 真值：组内所有 ACDL 廓线的 bin 按层段聚合的平均消光（km⁻¹） |
| DEM / DEM_m / Z_sfc | 三个"地表海拔"来源：DEM=ACDL 产品字段（**实为 km，agl 模式 ×1000 修复**）；DEM_m=修复后的逐组地表海拔（agl 产物新列）；Z_sfc=ERA5 地表位势/g0（平滑地形，训练附加列）。agl 口径下 dz/GCF 用 DEM_m |
| BLH / TCWV | 边界层高度 / 整层水汽含量（ERA5 单层列，作为模型附加 token 特征） |
| case1–5 | 匹配 QC 口径：1=云下全丢、2=云下 CAD 合格仍保留、3=云底 1km 缓冲带、4=厚云下全丢+薄云缓冲（ASL 时代默认）、**5=仅消光范围+地表以上（当前训练用，无云/CAD 过滤）** |
| ±30min / 0.18° | 匹配时间窗与空间距离上限：每条 ACDL 廓线吸附到最近整点（±30min）和最近 0.25° 格点（≤0.18°，防域外错配）。**一组内可有 1–5 条廓线（bin 级平均）** |
| 硬几何 / 云 QC / 其他 | 低层缺失三大成因：①地形切割（91–95%）；②云下剔除（case5 已回收 ~28pp）；③消光超界/CAD 不确定带/产品 NaN |

## 四、训练与评估流程

| 术语 | 解释 |
|------|------|
| **abs / frac** | 两种训练目标：abs=逐层绝对消光 σ(km⁻¹)（当前用）；frac=厚度加权逐层占比（只学形状，已弃） |
| 掩膜 Huber | 损失函数：只在该层有 ACDL 观测（isfinite）时计 Huber 损失，缺测层零贡献 |
| 逐层标准化 | 目标先按层减均值除标准差再计损失（每层相对误差等权） |
| Holdout / 留出集 | 随机抽 20% 样本（6,972）作测试集，seed=42 固定 → 所有实验可比。注意：随机划分，同格点/时次可能跨集，结论偏乐观 |
| **评估台（bench）** | `scripts/evaluate_bench.py`：从预测落盘 npz 计算四指标+EE 散点+分位带图，**不重训**。所有文档中的对比数字都出自它 |
| predictions_*.npz | 训练落盘的预测数组（y_true/y_pred/dz_km/gcf…），评估台与重画图的输入 |
| y_true 全等校验 | 旧 npz 补 dz 时用同 seed 重放留出索引并校验 y_true 全等——保证评估口径与训练严格一致 |
| 噪声底 = 0 | E0 对照与 B0 逐位一致 → 同 seed 下单次运行无随机涨落，指标差异全部来自配置改动 |
| **交叉验证 (CV)** | 比随机留出更严格的泛化检验：空间块 3×3（经纬度块留一，防同格点跨集）+ 时间块 4 折（按日期切块，防同时次跨集）。训练脚本 `--cv --cv-mode {both,spatial,temporal}` |

## 五、指标速记（计算与判读详见《[指标说明](指标说明.md)》）

| 术语 | 一句话 |
|------|--------|
| nMAE | 误差占观测均值的百分比（跨层可比主指标；低层 57%≈"报均值"水平） |
| MB | 带符号平均偏置（正=高估负=低估；与 nMAE 配对区分"总量型/重分布型"） |
| slope / intercept | 预测 vs 观测回归斜率/截距（slope<1 = 动态范围压缩，本项目主病灶） |
| OD | 整柱光学厚度 = Σ σ·Δz（同一套有效层掩膜） |
| Gfrac(EE) | 列级满意率：\|OD̂−OD\| ≤ 0.05+0.15×OD 的比例（≥66% 达标；列级口径，与逐层 EE 区分） |
| GCF | 近地面占比：层底<500m（AGL 口径=离地 500m）消光占整柱比例（PM2.5 最相关量） |
| log10 比值 | 逐层 log10(σ̂/σ) 中位数（+0.3=高估 2 倍；对称视角看尾部缺失） |
| 逐层 R² | 已降为附图：分母是各层自身方差，跨层不可比，仅同层纵向对比 |

## 六、目录与文件约定

| 路径/后缀 | 含义 |
|-----------|------|
| `结果汇总/` | 全部产物归档：runs（训练运行）、logs（日志）、figures（诊断/论文图）、6 份总结 md |
| `runs/<实验名>/results/` | 该次训练的指标：`cv_summary.json`（含配置快照）、`per_layer_metrics_*.csv`、`predictions_*.npz`、`bench_*.json/md` |
| `runs/<实验名>/plots/` | 该次训练的图（bench_* 三图 + per_layer_r2 + gcf_scatter） |
| `D:/matchdata_fixed_case5` | **ASL 历史产物**（只读，未做任何改动） |
| `D:/matchdata_agl_case5` | **AGL 新产物**（本次改造生成） |
| `--vertical {asl,agl}` | 匹配脚本垂直坐标开关（默认 asl） |
| Tag 后缀 | 输出文件命名：`Holdout_<tag>`（如 Holdout_AGLB0），对应实验编号 |
