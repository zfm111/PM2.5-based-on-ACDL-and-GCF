## 1. 总路线(回顾)

```
Stage 1: f1: ERA5 气象 → ACDL 消光廓线        ← 当前阶段
Stage 2: GCF = 近地面(0–500 m)光学厚度占比     ← 由廓线导出
Stage 3: f2: AOD + GCF + 地表气象 → 地面 PM2.5  ← 最终目标
```

**f1 的存在理由**:AOD 是柱积分、PM2.5 是地面,中间缺"垂直代表性";ACDL 只能在约 **2.4%** 的地方给出 GCF,必须补全才能进 Stage-3。

## 3. 关键判断(决定后续方向)

**瓶颈是"信息缺失",不是模型或调参:**

1. **含量缺失**:消光 ≈ 柱含量 × 形状。柱含量由排放/输送/湿沉降决定,**ERA5 气象廓线里没有** → `abs` 天花板就在 0.3 量级;
2. **形状缺驱动**:形状由 BLH、**风切变/输送**、层结控制 → 目前只有 T/RH/BLH,**风场未接**;
3. **近地面样本少**:GCF 需要的"近地面各层全有效"样本仅 **2.4%**,且强选择偏差(晴空少云)。

**由此,后续主线有三条(可并行):**
- **主线 A(诊断优先)**:先搞清"当前到底有多少技巧、上限在哪" —— 基线 + 消融 + 多种子;
- **主线 B(补信息)**:接风场 → 必要时接 AOD/气溶胶再分析;
- **主线 C(扩样本)**:换 QC 口径 / 重跑匹配,把近地面样本提一个量级。

**并且要始终准备一个"退路"**:若补了信息仍学不动,则改用 **"观测 + 插值"**(GCF 是归一化量,比消光平滑得多)或借 **CAMS/MERRA-2** 直接算 GCF。

## 4. 分阶段计划

### 阶段 0:诊断三连(1–2 周,最便宜、必须先做)

| # | 动作 | 产出 | 判据 |
|---|---|---|---|
| 0.1 | **加基线**:统一占比(1/32)、气候态平均廓线、persistence | 基线 R²/MAE 与模型并排 | 形状 R² 若低于基线 → 模型无效 |
| 0.2 | **特征消融**:仅 lon/lat/hour → +T/RH/H → +BLH/TCWV/Z_sfc | 各配置 R² 表 | 若前者已≈后者 → 气象已榨干 |
| 0.3 | **多种子**:`--seed 0,1,2` 跑 A/B | 均值 ± 标准差 | 差值 > 1σ 才算"有用" |
| 0.4 | **逐层有效数 + 分高度带汇总** | 哪些层几乎无监督 | 明确评估范围 |

**实现**:在 [train_acdl_era5_match_v2.py](train_acdl_era5_match_v2.py) 加 `--baseline` / `--features geoonly|met|full` / `--seeds` 三个开关 + 一个汇总表输出。

### 阶段 1:判定实验 —— f1 值不值得继续(1–2 周)

```
在有观测的样本上留一:
  ① 观测 GCF
  ② 邻域插值 GCF(时空克里金/加权回归)
  ③ f1 预测 GCF
比较三者误差(E_B vs E_f1)
```
- **若 ② 明显优于 ③** → f1 降级为"极端缺测兜底",主路径转插值/再分析;
- **若 ③ 接近或更好** → 继续主线 B/C。

### 阶段 2:补信息 + 扩样本(1–2 月)

| # | 动作 | 结果 |
|---|---|---|
| 2.1 | **接风场**:ERA5 单层 10 m u/v(如没有,取 ERA5-Land 0.1°,需双网格匹配) | 重估 GCF R²(期望:形状首次有信号) |
| 2.2 | **QC 口径对比**:`--case 5`(最全)vs `--case 2`(云下保留)vs `--case 4`(默认) | 样本量 vs 污染 的权衡曲线 |
| 2.3 | **全年重跑匹配**:2022.6–2023.5(输出到 `matchdata_v3/`;复用缓存,主要耗时在 ERA5 读取) | 12 个月 × ~20 万行 |
| 2.4 | **多月训练**:按月留出 CV + 分季节评估 | 去掉"单月乐观" |

### 阶段 3:模型与产品化(1–2 月)

| # | 动作 | 产出 |
|---|---|---|
| 3.1 | 高度条件化/沿高度建模(替代"池化→32 层硬输出") | 结构改进版模型 |
| 3.2 | **推理脚本**:加载 `model_final.pt`,对任意格点/时次生成 GCF 与消光廓线 | 逐格点逐小时的 **GCF 产品** |
| 3.3 | 与 ACDL 观测对比验证(独立时段/区域) | 产品精度报告 |
| 3.4 | 与 CAMS/MERRA-2 的 GCF 交叉比对(若接入) | 外部一致性检验 |

### 阶段 4:Stage-3(PM2.5 反演,2–4 月)

| # | 动作 | 关键点 |
|---|---|---|
| 4.1 | 接入 **FY-LDA AOD**(0.04°)+ 站点 PM2.5 + MODIS(土地覆盖/NDVI)+ DEM | 站点时空匹配 |
| 4.2 | 特征: AOD、GCF、ERA5 地表气象、DEM、下垫面、时空编码 | **GCF 是核心增量** |
| 4.3 | 模型:XGBoost/LightGBM 基线 → 时空模型;站点 CV(时间/站点/空间) | 与"不含 GCF"的对照消融 |
| 4.4 | 论证 GCF 的增益:有/无 GCF 的 R² 对比 | **论文核心结论** |

## 5. 里程碑与 Go / No-Go 判据

| 里程碑 | 时间 | 判据(通过 → 继续;不通过 → 转备选) |
|---|---|---|
| **M1** 诊断完成 | +2 周 | 拿到基线/消融/多种子结果;明确"当前技巧有多少" |
| **M2** f1 判定 | +4 周 | 插值 vs 模型对比;若插值胜出 → 改走插值路线 |
| **M3** 风场接入 | +8 周 | 真 CV 下 **GCF R² ≥ 0.4** → f1 路线成立;0.2–0.4 → 降级为兜底;**<0.2 → 放弃纯气象 f1** |
| **M4** 全年数据 | +10 周 | 12 个月匹配完成,多月训练 CV 稳定 |
| **M5** GCF 产品 | +14 周 | 推理脚本产出逐格点 GCF,与观测对比达标 |
| **M6** PM2.5 反演 | +22 周 | 站点 CV 的 R²/RMSE 达标;**有 GCF 显著优于无 GCF** |

## 6. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 形状/GCF 本质上不可由气象预测 | f1 主目标落空 | 早做 M2 判定;预留插值/再分析退路 |
| ACDL 近地面有效样本过少(2.4%) | 形状头欠拟合、偏差大 | `--case 2/5` 重跑匹配扩大样本;或降低 GCF 窗口要求 |
| 全年匹配耗时/磁盘 | 进度拖延 | 复用日级缓存;`--jobs N` 并行;按需只跑需要的月份 |
| 风场需 ERA5-Land 0.1°(双网格) | 匹配复杂度上升 | 优先查 ERA5 单层是否已有 10 m 风;否则按"双网格各自最近节点"处理并在文档记录口径 |
| AOD 与消光同源导致"自证" | 结论被质疑 | AOD 只进 Stage-3 输入;Stage-1/2 不使用 AOD 作输入(避免循环论证) |
| 单月结论外推 | 泛化被高估 | 一律以 M4(全年+按月 CV)为准 |

## 7. 立刻要做的三件事(本周)

1. **`--baseline` 开关**:把"气候态平均廓线"基线与模型并排输出(半天;没有它,形状 R² 无法解释);
2. **多种子 A/B**:`--seeds 0,1,2` 跑"有/无 BLH"两组(1 天;把"特征是否有用"钉死);
3. **`--case 5` 匹配 + 训练对比**:验证"是不是 QC 把近地面数据杀太狠"(1–2 天;同时给出样本量 vs 污染的权衡)。

---

## 8. 一句话总结

> 数据与流程**已经打通**(匹配 135 列、训练三口径、CV 与出图齐全),**当前卡点不是工程而是信息**:气象里没有"气溶胶有多少",风场还没接,近地面样本只有 2.4%。
> 下一步顺序:**先诊断(基线/消融/多种子)→ 再判定(f1 vs 插值)→ 再补信息(风场,必要时 AOD/再分析)与扩样本(全年 + 宽 QC)**;并设好 Go/No-Go(M3:GCF R² ≥0.4 继续,<0.2 转路线)。
