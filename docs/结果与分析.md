## 第 1 页 · 结果(一):核心指标 GCF 的精度

**要点**(配图:`gcf_scatter_Holdout.png`)

- 留出集散点:横轴观测 GCF,纵轴预测 GCF,虚线为 1:1 参考线
- **关键读数:R² = 0.423,MAE = 0.042,n = 2079**
- 对照研究设计设定的判定线(**GCF R² ≥ 0.4**)→ **已达到该水平**,用 ERA5 气象场补全 GCF 的路线**成立**
- 分布特征:
  - 观测 GCF 集中于**低值端**(多数 < 0.1);
  - 预测值集中在 0.05–0.25,呈**向均值收缩**——低值端略有高估、高值端有所低估(回归类模型的普遍特征)
- **意义**:GCF 是 Stage-3 真正的输入量,这是目前**最直接可用的定量结论**

**讲稿**

这一页是核心结果,即 GCF 的留出集精度。图中横轴为观测值、纵轴为预测值,虚线为 1:1 参考线,样本量 2079,R² 为 0.423,平均绝对误差为 0.042。按照研究设计中设定的判定标准,GCF 的 R² 达到 0.4 即说明用 ERA5 气象场补全 GCF 的路线成立,当前结果已达到这一水平。从分布上看,观测 GCF 主要集中在低值端,预测值集中于 0.05 到 0.25 之间,表现为向均值收缩:低值端略有高估、高值端有所低估,这是回归类模型的普遍特征。GCF 是第三阶段真正的输入量,因此这是目前最直接可用的定量结论。

**需注意(汇报前核对)**

- 图例文字写作 **"used in training (n=2079)"**,与标题 **"Holdout"** 不一致 → 需核对绘图脚本标签,避免被质疑评测口径;
- GCF 观测值偏低聚集是否受 QC 口径影响(不做云过滤时,高层云消光计入分母会系统性压低 GCF)→ 建议叠加另一 QC 口径作对照;
- MAE 0.042 相对 GCF 常见量级(0.05–0.1)仍不可忽略 → Stage-3 中需评估对**低 GCF 情形**的识别能力;
- 当前为随机留出。按路线图 M3 的口径,**还需以多种子 + 多月 CV 复核**。

## 第 2 页 · 结果(二):逐层消光精度(成功匹配)

**要点**(配图:`per_layer_r2_abs_case5.png`)

- 口径:case5(最宽松质控),留出集 **n = 34860**;左轴高度、右轴近似气压
- **逐层 R² 全部为正**,整体约 **0.25–0.81**,呈明显的**分层结构**:

| 高度带 | 逐层 R²(读图近似) | 特征 |
|---|---|---|
| 高空 > 15 km | **0.6–0.8**(20 km 附近最高,约 0.80) | 结构稳定,主要由气候态控制 |
| 中层 5–15 km | 0.5–0.7 | 中等,含输送结构 |
| **近地面 < 5 km** | **0.25–0.45**(1 km 附近最低,约 0.25) | 难点集中段 |

- **分析**:高层气溶胶结构稳定、以气候态为主 → 易学;近地面受**边界层演变、排放与输送的瞬时变化**控制 → 难度最高,**而这正是 GCF 所关心的高度段**

**讲稿**

这一页是成功匹配条件下的逐层消光精度。左轴为高度、右轴为近似气压,横轴为留出集的逐层 R²,样本量 34860,采用最宽松的 case5 质控口径。可以看到所有层都取得了正的精度,整体在 0.25 到 0.81 之间。分层特征是:15 公里以上精度最高,约 0.6 到 0.8,20 公里附近接近 0.8;5 到 15 公里为 0.5 到 0.7;近地面 5 公里以下为 0.25 到 0.45,最低出现在 1 公里附近。这符合物理直觉:高层气溶胶结构稳定、主要由气候态控制,因此易于学习;近地面受边界层演变、排放与输送的瞬时变化控制,是难点最集中的高度段,而这恰好是 GCF 所关心的高度范围。

## 第 3 页 · 结果(三):匹配正确性的对照实验

**要点**(配图:`per_layer_r2_Holdout_wrong_match.png`)

- **错误匹配的成因**:ACDL 为全球覆盖,ERA5 限定在研究区(73–135°E / 3–54°N)→ 研究区外的 ACDL 足印被吸附到 ERA5 范围**边界**,形成位置错位的样本对
- **结果**:逐层 R² 降至约 **0.05–0.40**(多数层 0.1–0.25),相比成功匹配整体下降约 **2–3 倍**
- 分层对比:

| 高度带 | 成功匹配 | 错误匹配 |
|---|---|---|
| 高空 > 15 km | 0.6–0.8 | ~0.3–0.4 |
| 中层 5–15 km | 0.5–0.7 | ~0.15–0.25 |
| 近地面 < 5 km | 0.25–0.45 | **~0.08–0.10** |

- **结论**:高空仍保留约 0.3–0.4,说明气候态背景本身仍提供部分解释力;**近地面几乎失去技巧** → **近地面逐层精度是判别匹配质量最灵敏的指标**
- **对流程的意义**:直接验证了「0.25° 节点匹配 + 域外足印处理」的必要性 → 应在匹配中保留**域外足印剔除**与**节点距离 QC 记录**

**讲稿**

这一页是对照实验。ACDL 是全球覆盖的数据,而 ERA5 只覆盖我们的研究范围,因此按早先的匹配策略,研究范围以外的 ACDL 足印会被吸附到 ERA5 范围的边界节点上,形成位置错误的样本对。图中给出这类错误匹配下的逐层精度:整体降到 0.05 到 0.40,多数层在 0.1 到 0.25 之间。分层上看,高空仍有约 0.3 到 0.4,说明气候态背景本身仍提供一定解释力;而近地面降到 0.08 到 0.10,几乎失去技巧。这说明近地面逐层精度对匹配质量最为敏感,匹配的地理正确性是结果有效的前提;该对照也直接验证了我们采用 0.25 度节点匹配、并需要处理域外足印的必要性。

**需注意(汇报前核对)**

- 两图 **x 轴量程不同**(0.8 vs 0.40),并列汇报会造成视觉误导 → 建议**统一量程**后再对比;
- 错误匹配图**未标注 n 与 QC 口径** → 严格可比需补齐(case5 与对应样本量);
- 图例显示为 `Holdout (mean) (mean)`,疑为绘图脚本标签重复拼接 → 需核对是否为多种子/多折平均,并写清口径。

## 第 4 页 · 分析与小结

**要点**

**三条主要结论**

1. **路线成立**:GCF 留出集 R² = **0.423**、MAE = 0.042,达到设计判定线 → 用 ERA5 气象场补全 GCF 可行
2. **精度分层清晰**:高空(0.6–0.8) > 中层(0.5–0.7) > 近地面(0.25–0.45);**难点集中在 GCF 所关心的高度段**
3. **数据管线正确性是前提**:错误匹配使逐层精度整体下降 2–3 倍,近地面几乎归零

**对 Stage-3 的意义**

- GCF 已可作为**显式变量**进入 PM2.5 反演 → 下一步以「**有 / 无 GCF**」的精度对比给出最终结论

**下一步**

| 方向 | 动作 |
|---|---|
| 补信息 | 接入风场 u/v(垂直形状的关键驱动) |
| 扩样本 | 匹配扩展至全年(2022.6–2023.5),分季节评估 |
| 强评估 | 基线对照(统一占比、气候态平均廓线、persistence)+ 特征消融 + 多种子 / 多月 CV |
| 规范口径 | 统一 QC 口径与图件量程,补齐各图 n 与标签 |

**讲稿**

小结三点。第一,路线成立:GCF 的留出集 R² 为 0.423,达到我们设定的判定水平,平均绝对误差为 0.042,说明用 ERA5 气象场补全 GCF 是可行的。第二,精度随高度分层清晰:高层最高,近地面最低,难点恰好集中在 GCF 所关心的高度段。第三,数据管线的正确性是前提:错误匹配会使逐层精度整体下降两到三倍,近地面几乎失去技巧。因此 GCF 已经可以作为显式变量进入第三阶段的 PM2.5 反演,下一步将通过有、无 GCF 的精度对比给出最终结论;同时接入风场、把匹配扩展到全年样本,并以基线对照、特征消融与多月交叉验证来强化评估,统一评测口径与图件量程。
