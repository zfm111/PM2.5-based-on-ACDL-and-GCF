# 为什么做 f1:ERA5 气象 → ACDL 消光廓线

> 本文说明**研究动机与定位**:我们为什么要把
> `ACDL 消光廓线(2022.6.1–2023.5.31) = f1(ERA5 温度廓线、湿度廓线、边界层高度、地理坐标、月份、时刻)`
> 当作一个独立的建模步骤来做。
>
> 本文只讲"为什么"和"边界";**实现细节**见
> [ACDL_ERA5_FromScratch_Matching_Strategy.md](ACDL_ERA5_FromScratch_Matching_Strategy.md)(匹配与列布局)、
> [train_acdl_era5_match_v2_README.md](train_acdl_era5_match_v2_README.md)(训练)。

---

## 1. 这一步在整条研究链条里的位置

```
  ┌─ Stage 1(本文) ─────────────┐   ┌─ Stage 2 ─┐   ┌─ Stage 3 ─────────────┐
  ERA5 气象(廓线+单层)  ──f1──►  ACDL 消光廓线  ──►  GCF  ──►  与 AOD 一起反演地面 PM2.5
  └──────────────────────────────┘   └───────────┘   └───────────────────────┘
```

- **Stage 1(f1)**:学 ERA5 → 消光廓线的映射;
- **Stage 2**:由廓线算 **GCF**(近地面 0–500 m 的光学厚度 / 整柱光学厚度);
- **Stage 3**:`PM2.5 = f2(AOD, GCF, ERA5 地表气象, DEM, …)`。

**f1 存在的唯一目的,是让 GCF 在"没有 ACDL 观测的地方"也能得到。**

---

## 2. 为什么需要 GCF —— 问题出在"AOD 是柱、PM2.5 是地面"

| | 观测内容 | 空间代表性 |
|---|---|---|
| **卫星 AOD** | 整层大气(0–30 km)气溶胶的**柱积分** | 与地面 PM2.5 存在**垂直代表性差异** |
| **地面 PM2.5** | 近地面(几米)质量浓度 | 关心的是**贴地**那一层 |

同一个 AOD 可以对应完全不同的地面 PM2.5:

- 气溶胶**集中在近地面**(静稳、逆温、边界层浅)→ 同样的 AOD 对应**高** PM2.5;
- 气溶胶**大量分布在高层**(沙尘抬升、高空烟霾输送)→ 同样的 AOD 对应**低** PM2.5。

`GCF`(近地面占比)正是量化这一差异的量:

```
GCF = ∫₀^500m σ(z)dz / ∫₀^30km σ(z)dz
GCF → 1:气溶胶几乎全在近地面,AOD 与 PM2.5 关系紧密
GCF → 0:气溶胶主要在高空,AOD 会高估地面 PM2.5 的代表性
```

**没有 GCF,AOD→PM2.5 的回归会把两种情形混在一起,产生系统性偏差;GCF 是这条链条上最缺、也最关键的一环。**

---

## 3. 为什么不能"直接用 ACDL 的 GCF" —— 覆盖不够

ACDL 是星载激光雷达,只在**轨迹上**、且**近地面可用**的地方给出廓线。实测统计(2022 年 6 月,20.5 万条 (格点,时次) 样本):

| 口径 | 可用样本 | 占比 |
|---|---|---|
| 柱含量可用(≥3 层有效) | 98,981 | 48.2% |
| 形状/GCF 可用(≥10 层且厚度覆盖 ≥50%) | 8,247 | 4.0% |
| **近地面完整**(GCF 定义所需层全有效) | **4,928** | **2.4%** |

也就是说:**ACDL 能诚实地给出 GCF 的地方只有约 2.4%**,而且是"晴空、少云"的选择性子集。要把它用作 Stage-3 的**输入场**(逐格点、逐小时的 GCF 图),就必须把它**补到没有观测的地方**。

**而 ERA5 是唯一"处处都有、逐小时、带垂直结构"的现成输入** —— 这就是 f1 的由来:用"处处都有的气象"去生成"只有少数地方才有的廓线/GCF"。

---

## 4. 为什么 f1 的输入是这几样(逐变量的物理依据)

| 输入 | 物理作用 | 支撑的是 |
|---|---|---|
| **温度廓线 T(z)** | 层结稳定性、逆温强度 → 决定气溶胶能否垂直混合、是否被"压"在近地面 | **形状/GCF** |
| **湿度廓线 RH(z)** | 吸湿增长:消光对相对湿度强依赖(σ ≈ σ_dry·f(RH));也指示云/雾倾向 | **绝对值 + 形状** |
| **边界层高度 BLH** | 边界层厚度直接决定近地面气溶胶的**稀释/堆积** → 近地面占比 | **GCF(最直接的驱动)** |
| **地理坐标 (lon, lat)** | 源区分布(城市群、沙漠、海洋)、地形气候态 | 气候态背景 |
| **月份 / 时刻** | 季节循环(沙尘季、采暖期)与日变化(边界层日循环、排放日循环) | 气候态 + 日变化 |

> 关键对应关系:**消光 ≈ 柱含量 × 垂直形状**。
> - **形状**由 BLH、层结、湿度、输送决定 → **理论上可由气象学到**;
> - **柱含量**由排放、输送、湿沉降决定 → **气象廓线给不了**(这是 f1 的天然上限,见 §6)。

---

## 5. 数据与形式化定义

**样本**:一个样本 = 一个 **(0.25° ERA5 格点 × 整点时次)**,由落入该格点、该小时 ±30 min 内的 ACDL 廓线平均、并垂直降采样到 ERA5 的 32 个层段得到。

**目标(逐样本 32 维)**:`σ_l`(第 l 个 ERA5 层段的 ACDL 平均消光,km⁻¹);无有效观测的层为 NaN → 训练时掩膜。

**输入**:
```
X = [ lon, lat, sin(hour), cos(hour),            ← 地理坐标 + 时刻
      H_k(32), T_k(32), RH_k(32),                ← ERA5 廓线(位势高度/温度/湿度)
      BLH, TCWV, Z_sfc ]                         ← ERA5 单层(边界层高度/柱水汽/地形高度)
```

**时间与空间范围**:2022.6.1–2023.5.31(一年),区域 73–135°E / 3–54°N;ERA5 为 0.25° 逐小时。

**三种建模口径**(见训练文档 §1):
| 口径 | 目标 | 用途 |
|---|---|---|
| `abs` | 绝对消光 σ_l | 重建廓线本身 |
| `frac` | 厚度加权逐层占比 f_l(和为 1)→ **形状** | 直接导出 GCF |
| `multi` | 形状 + 柱含量 OD | 二者相乘可还原绝对廓线 |

## 6. 现状与诚实的边界(截至 2026-09-21)

**已观察到的结果**

| 口径 | 指标(随机留出,偏乐观) | 解读 |
|---|---|---|
| `abs` 绝对消光 | 全局 R² ≈ **0.28–0.31**;逐层 0.04–0.39 | 有信号,但主要来自**气候态**部分 |
| `frac` 形状 | 逐层 R² **为负** | **模型不如直接输出平均廓线** |
| GCF | R² **为负** | 形状学不动 → GCF 学不动 |
| 柱含量 OD | R² ≈ +0.34 | 反而有一点信号(含地理/气候态信息) |

**加入 BLH / TCWV / 地形后,`abs` 基本没有变化** → 说明这几样**不携带"气溶胶有多少"的信息**。

**由此得到的判断(重要)**
1. **绝对消光**的天花板由"柱含量不可观测"决定 —— ERA5 里没有气溶胶的排放/输送/清除信息;
2. **形状/GCF** 理论上可学,但目前证据不利,可能的原因:
   - 近地面样本仅 **2.4%**,且强选择偏差(晴空少云);
   - 形状的关键驱动里 **风场/输送尚未接入**(目前只有 T/RH/BLH);
   - 纯气象对"相对分布"的解释力本身有限。
3. 因此 **f1 的 KPI 应当是 GCF 的误差,而不是消光本身的 R²** —— 前者才是 Stage-3 真正需要的量。

---

## 7. 这条路线的前提,以及备选方案

**成立前提**(任一不满足,就该换路线):
- 加入 **风场(u/v)、垂直速度** 等输送变量后,GCF 的误差显著改善;
- 或引入**气溶胶信息**(AOD、CAMS/MERRA-2 逐层气溶胶)后,形状/含量之一变得可预测;
- 或通过 `--case 2` 等更宽松的 QC 重跑匹配,把近地面样本从 2.4% 提升一个量级。

**备选方案(与 f1 并列,按实现成本排序)**

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A. 观测 + 插值(推荐评估)** | 只在有观测处算 GCF,再用克里金/回归/时空插值补缺 | 最简单;**GCF 是归一化量,比消光平滑得多**,插值往往优于"从零生成" | 观测稀疏区仍差 |
| **B. 观测约束的补缺(混合)** | 保留 f1,但输入里加入**时空邻域已观测的廓线/GCF**(轻量数据同化) | 把观测信息引入,绕开纯气象的天花板 | 需重构特征与样本组织 |
| **C. 借气溶胶再分析** | 用 CAMS/MERRA-2 逐层气溶胶直接算 GCF(或作为 f1 输入) | 时空连续、无需观测 | 模式偏差;需下载/转换/匹配 |
| **D. 降级 f1** | 只把 f1 当"极端缺测处的兜底填充",主路径用 A 或 C | 不再在低信号上投入 | 产品精度依赖兜底质量 |

## 8. 下一步的判定实验(决定 f1 是否继续、以何种形态继续)

1. **GCF 路线对比**(最便宜、最直接):
   ```
   在有观测的样本上做留一:① 观测 GCF ② 邻域插值 GCF ③ f1 预测 GCF
   比较三者误差:若 ② 明显优于 ③ → 转向"插值"路线;若 ③ 接近或更好 → 继续 f1
   ```
2. **接入风场后重估**:加 u/v(必要时加垂直速度)后看 `GCF_R²` 是否转正;
3. **扩大近地面样本**:用 `--case 2`(云下 CAD 合格即保留)重跑匹配,把 2.4% 提上去后重训形状头;
4. **基线与消融**:统一占比(1/32)、气候态平均廓线、persistence 三条基线 + 特征消融 → 量化"气象到底解释了多少"。

**判据(建议)**:若在加入风场与更大样本后 **GCF 的 R² 仍 < 0.2**,则停止在 f1 上继续投入,转向方案 A/C。

---

## 9. 一句话总结

> **做 f1,不是因为"想预测消光",而是因为 AOD→PM2.5 的反演缺一个"垂直代表性"的量(GCF),而 ACDL 只能在 2.4% 的地方给出它。**
> f1 试图用"处处都有的 ERA5 气象"把 GCF 补全 —— 第一步(绝对消光)有微弱信号但受"柱含量不可观测"限制;第二步(形状/GCF)目前学不动,最可能的原因是**缺输送类变量 + 近地面样本太少**。
> 因此接下来要做的不是继续调网络,而是**补风场/扩样本**,并用"插值 vs 模型"的对比实验来决定 f1 是否还有必要以现在的形态存在。
